## 🎯 ماذا يجب أن أعرف الآن؟ (What should I know now?)

**قبل هذا المستوى:** لا شيء تقنيًا. فقط أنك تستخدم حاسوبًا.

**بعد هذا المستوى** يجب أن تستطيع الإجابة بثقة، بكلماتك، على:

- ما هو الحاسوب؟ ما الفرق بين hardware و software؟
- ما هو البرنامج؟ ما الفرق بين source code و machine code؟
- ما هو compiler؟ interpreter؟ runtime؟
- ماذا يحدث **فعلًا** عندما أشغّل برنامجًا؟
- ما هو نظام التشغيل (OS) وماذا يفعل؟
- ما هو process؟ ما هي الذاكرة (memory)؟ ما هو الملف (file)؟
- كيف أتنقل في terminal؟ ما هو path؟ ما هو environment variable؟
- ما هو port؟ ما هو localhost؟ ما هو IP address؟
- ما هي الشبكة؟ ما هو server؟ ما هو client؟ ماذا يفعل المتصفح؟
- ما هي قاعدة البيانات؟ ما هو API؟ ما هو web application؟

**والأهم:** أن ترسم من ذاكرتك هذه الخريطة وتشرح كل سهم فيها:

```
Human
 ↓
Source Code
 ↓
Compiler / Runtime
 ↓
Machine
 ↓
Operating System
 ↓
Network / Storage
 ↓
Application
```
