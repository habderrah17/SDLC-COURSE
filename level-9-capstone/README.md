## ✅ التقييم الذاتي النهائي (Final Self-Assessment)

أجب بصدق — **بكلماتك، بمثال من عندك**:

| # | هل أستطيع… | المستوى المرجعي |
|---|---|---|
| 1 | شرح كيف يُنفَّذ برنامج من الكود المصدري حتى المعالج؟ | L0, L2 |
| 2 | شرح ما هي العملية (process) ولماذا ذاكرتها معزولة؟ | L0, L2 |
| 3 | شرح الذاكرة: stack, heap, references, GC, leaks؟ | L2 |
| 4 | شرح HTTP من TCP حتى status codes وcaching وcookies؟ | L2, L5 |
| 5 | شرح database transaction وACID بمثال، ومتى أحتاجها؟ | L3 |
| 6 | شرح race condition بمثال من منطق عمل، وكيف أمنعها؟ | L5 |
| 7 | شرح authentication: hashing, sessions, tokens, cookies flags؟ | L5 |
| 8 | شرح authorization: roles, ownership, tenant isolation؟ | L5 |
| 9 | تصميم API احترافي بـ pagination, versioning, idempotency, errors؟ | L5 |
| 10 | تصحيح كود في مستودع لم أره من قبل، بمنهجية؟ | L4 |
| 11 | مراجعة PR بقائمة Correctness/Security/Perf/Architecture/Tests/Maintainability؟ | L6 |
| 12 | تصميم نظام بعملية 11 خطوة مع مقايضات صريحة؟ | L7 |
| 13 | التفكير في الفشل: timeouts, retries, idempotency, degradation؟ | L7 |
| 14 | قراءة logs/metrics/traces وفهم ما يفعله الإنتاج؟ | L6 |
| 15 | نشر برنامج بـ Docker + CI/CD + rollback؟ | L5 |
| 16 | استخدام AI دون الثقة العمياء، بسلسلة تحقق كاملة؟ | L8 |

**أي "لا" = ارجع للمستوى المرجعي قبل التحدي النهائي.**

## 🏁 التحدي الاحترافي النهائي (Final Professional Challenge)

ستُعطى **مشكلة برمجية جديدة كليًا** (ليست SaaS التخرج). **لا حل يُقدَّم.** يجب أن تنجز **بنفسك**:

```
 1. Understand the problem
 2. Ask / identify missing requirements
 3. Define assumptions
 4. Define acceptance criteria
 5. Model the domain
 6. Design architecture
 7. Design data
 8. Define APIs
 9. Threat-model
10. Implement
11. Test
12. Review
13. Deploy
14. Observe
15. Iterate
```

> يُقدَّم التحدي في `level-9-capstone/final-challenge.md` — **افتحه فقط بعد اجتياز التقييم الذاتي.**
